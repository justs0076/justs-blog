About JustS

JustS is a small independent project focused on building useful things for the web.

The goal is simple: create tools that are fast, straightforward, and useful, while exploring ideas around software development, technology, systems, personal finance, and other subjects worth understanding.

The tools are designed to be easy to use and, where practical, process information directly in the browser rather than requiring users to upload their data to a remote service.

03

What's next

JustS is currently being expanded with additional browser-based tools and original writing.

New projects will be added as they are completed, with an emphasis on keeping each tool focused, lightweight, and useful.
